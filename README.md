# ⚔️ Gladiator Arena

Gladiator Arena is a 2D action-combat game developed in Python using Pygame. Players enter a brutal arena and fight against increasingly difficult enemies while managing health, resources, and survival strategies.

The project was built to explore game development concepts such as object-oriented programming, combat mechanics, enemy AI, animation systems, save systems, particle effects, and user interface design.

---

## 🎮 Features

### Combat System
- Real-time combat mechanics
- Player attack and damage system
- Enemy attack behaviors
- Health management
- Basic battle balancing

### Enemy AI
- Enemy detection and tracking
- Movement toward the player
- Automated combat decisions
- Progressive combat encounters

### Player System
- Character movement
- Health and survival management
- Combat interactions
- Stat tracking

### Visual Effects
- Character animations
- Particle effects
- Combat feedback effects
- Arena visual enhancements

### Game Systems
- Save and load functionality
- Settings management
- Sound management
- User interface system

### Arena Management
- Arena-based combat gameplay
- Enemy spawning mechanics
- Game progression system

## Installation

git clone https://github.com/karasmaiAS/Gladiator_arena.git

Navigate to Project: cd Gladiator_arena
Install Dependencies: pip install pygame
Run the Game: python main.py
